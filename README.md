# Landing Page

A one-page website built to practice CSS fundamentals and Flexbox. This project is part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Page Structure

The page has four main sections, plus a footer.

1. **Hero:** header logo, navigation links, main title, subtext, "Sign up" button and an image
2. **Information:** a heading with four boxes in a row, each with a short caption
3. **Quote:** a large italic testimonial with its author
4. **Call to Action:** a blue banner with a message and a "Sign up" button

**Footer:** copyright notice

## What I Practiced

- Structuring a page with semantic HTML
- The CSS box model (margin, padding, border)
- Typography (font size, weight, style and color)
- Flexbox layouts with `display: flex`
- Alignment with `justify-content` and `align-items`
- Spacing with `gap`
- Row and column layouts with `flex-direction`
